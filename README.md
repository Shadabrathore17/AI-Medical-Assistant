# AI Medical Assistant

AI-powered medical guidance system built using Python, Gradio, and CSV dataset support.

## Features

- Disease detection
- Medicine recommendation
- Symptoms explanation
- Medicine usage instructions
- Side effects information
- Precautions and warnings
- Hinglish, Hindi, and English support
- Offline working system
- 1100+ medical dataset records
- User-friendly web interface

---

## Technologies Used

- Python
- Gradio
- Pandas
- RapidFuzz
- CSV Dataset
